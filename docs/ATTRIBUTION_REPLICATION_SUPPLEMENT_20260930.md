# Replication sensitivity supplement

After the completed four-replica development label diagnostic, 2v2 terminal
pair ranks still disagree substantially. This leaves a concrete ambiguity:
weak expected action effects versus Monte Carlo error. Before interpreting
held-out closure outcomes, extend only a predetermined development panel:
five families × seeds {0,3,7,11,15,19}, initial checkpoint, to 32 replicas.

Keep the primary protocol, students, held-out seeds, and policies unchanged.
Keep first four replicas exactly; add replicas 4–31 under both full-budget rule
and local continuations, six unit sampling actions. Compare selection on
R={1,2,4,8,16} replicas against a disjoint fixed half of 16 evaluation replicas;
reverse halves and average. This panel has six independent seeds per family,
so it diagnoses Monte Carlo sensitivity, not a new broad confirmation claim.

No samples are chosen by action outcome, apparent gap, or held-out performance.
