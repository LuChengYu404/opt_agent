# Corrected-GP follow-up (frozen before main results)

Purpose: test whether coherent GP input handling changes the action portfolio,
whether terminal first-action differences survive a strong continuation, and
whether five-step blocks carry more independently measurable signal than a
single intervention. This is a BOCoDe-focused follow-up, not an LLM rerun or
a universal optimality test. Preserve the first attribution archive.

## Backend treatment

Enable bounds-based Normalize for all GP-backed actions using the backend's
explicit normalize_inputs option. Fit and restore share GP construction;
snapshots preserve this option, including unfitted snapshots. Legacy fitted
snapshots infer their transform from the saved model. Raw controls remain
available to reproduce old experiments; the production default stays raw.
IOH has the same explicit option, but this follow-up does not rerun its panel.

No changes to action parameters, GP kernel/prior, acquisition optimizer,
objective sign, or real evaluation budget. The six sampling actions each
evaluate one point. No standalone refit or STOP.

## Panels

1. Development: all five original families, seeds 20–29. Six fixed actions
   under raw and normalized GP, plus four normalized global-to-local schedules
   at .2/.4/.6/.8. Total 800 trajectories. Choose the best normalized fixed
   action and best normalized schedule per family on this development panel
   only; preserve raw action rankings as a diagnostic.
2. Labels: seeds 20–24, states at exactly 5, 15, 25 evaluations generated by
   the frozen normalized best fixed strategy: 75 states. Save each identical
   history, fit raw and normalized GP before extracting features, then simulate
   all six actions with block length 1 or 5 (four treatment profiles). After
   the block, execute the SAME frozen normalized-best action type to budget 30,
   using the GP treatment of that profile. Eight independent replicas per
   profile; paired random streams across treatments/actions/blocks. Each path
   records first-step, third-step and terminal improvement, the first proposed
   point, and GP std at that point. Both block lengths retain the real budget.
   Choosing/evaluating an action uses disjoint four-replica halves and reverses
   the halves. Also report each half against the frozen fixed first action,
   not just a retrospectively selected empirical constant.
3. Main test: fresh seeds 2000–2019, all families, six fixed actions raw and
   normalized plus the frozen normalized schedule: 1300 trajectories.
4. Privileged terminal reference: fresh seeds 2000–2009, all families,
   block lengths 1 and 5, four planning replicas. Total 100 trajectories.
   Replan at real counts 5,10,15,20,25 for BOTH arms. Unit arm applies its
   chosen action once then the frozen strong action for four points; block
   arm applies its chosen action five times. Counterfactual planning follows
   that intervention with the strong fixed continuation to budget 30.
   Same planning frequency isolates block duration from replanning frequency.
   Record planning objective calls/fits separately; privileged references
   are not deployable optimizers or optimal oracles.
5. Analytic positive control: sphere f(x)=-x^2 on [-5,5], five identical
   initial points at x=.5 (near) or x=3.5 (far), one remaining evaluation.
   Existing global/local actions with local step .1. Select on 256 replicas,
   evaluate on 2048 disjoint replicas using shared streams. Exact expected
   improvement: global=x^3*(2/15); local=1/12 for near, x/2-1/6 for far.
   Optimal state choice is local near/global far; equal-state adaptive gain
   over best constant global is 1/30. Verify these integrals and held-out gain.
   This controlled one-decision test checks measurement machinery, not BOCoDe
   closed-loop transfer. Candidate calls are not included in 2200 BOCoDe loops.

## Interpretation and checks

Total BOCoDe closed loops: 2200. Pair all methods on identical initial points.
The normalized baseline comparison is confirmatory within this fresh panel;
label/privileged block contrasts are exploratory (only five development seeds
or ten test seeds per family). No training or tuning on this test panel.
Do not train a new student unless independently evaluated label advantage
and closed-loop opportunity are demonstrated. These experiments decide which
signal should be supervised before more training.

Report paired seed bootstrap 95%/99% intervals and sign-randomization p with
Holm adjustment across five families per predeclared contrast. Label states
cluster by seed (three checkpoints are not independent). Normalization costs
no real evaluations; pre-feature fits and simulated fits are separately recorded.
Check bounds transform, fitted/unfitted/legacy restore, all GP actions, identical
first-step prefixes, exact budget, planning state/RNG restore and disjoint
selection/evaluation replicas. Failures are retained; never silently discard.
Provenance includes hashes of runner, protocol, production backend/checkpoint,
action/state code, reused helpers, development selections and environment.
