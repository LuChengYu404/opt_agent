# EXP-META-CONFIG-GRID — 初始设计规模的剂量-反应扩展：配置条件性确立

**日期**：2026-09-29（分支 `exp/boundary-scheme-round2`）
**工件**：`runs/exp_meta_config_grid.json`（主网格，5 族 × 4 档 × 60 种子，
1200 条逐轨迹记录）；`runs/exp_meta_config_grid_rastrigin240.json`
（Rastrigin 单族深采样臂，4 档 × 240 种子）
**脚本**：`scripts/exp_meta_config_grid.py`（估计量、假设与判定规则内嵌
预宣告）

## 摘要

本实验按筛选报告（`EXP_META_CONFIG_SCREEN.md` §6）预宣告的升级路径
执行两项扩展：增加配置档位（n_init ∈ {5, 8, 12, 18}）与增加种子
（20 → 60，原样本嵌套）。在维度归一化设计规模 c = n_init/(2d+1) 空间
中，以各族**参照标准化**剂量-反应斜率（b_f / sd_ref，尺度稳定）的
同质性为主检验（联合种子重抽样 SE，含 sd_ref 估计不确定性），
**配置条件性被检出**：χ²₄ = 20.06，p = 5×10⁻⁴，I² = 80%（原始单位
斜率的次要版本：χ²₄ = 30.87，同判）。结构为：三个光滑族的负斜率逐族
显著（Hartmann per-sd −0.84，p < 10⁻⁴；Branin −1.56，p = 0.002；
SixHumpCamel −0.30，p = 0.0007），多峰高维的 Ackley 呈显著正斜率
（+0.45 sd/单位 c，p = 0.029）。两项更正随之确立：(i) 筛选实验的
Rastrigin 结论（Δ₁₂ = +8.36，p = 0.032）**未能在新种子上复制**——
种子 0–19 与原工件逐位一致，新增种子 20–59 均值为 −3.30；n = 240 的
深采样臂显示其效应至多小且边际（L = 18 对参照 +2.20 [−0.47, 4.82]，
d_z = 0.11；斜率单侧 p = 0.049）。(ii) 两档对比（12 vs 5）在同质性
检验下于 n = 60 仍为边缘（p = 0.059）——剂量-反应形式化（利用全部
四档）以远高于单对比的检验力解决了筛选实验的 INCONCLUSIVE。

## 1. 研究问题

筛选实验（同日）在两档设计下未能判定"配置优势是否因族而异"
（χ²₄ = 8.71，p = 0.069），并预宣告了两条升级路径：加种子、加配置
档位。本实验同时执行两条路径，主问题不变：

> **Q**：设计期配置（初始设计规模）的优势是否存在族间异质性
> （family × dose 交互）？

## 2. 估计量与预宣告假设

**模型**：y_{f,s,L} = μ + α_f + β_{c(f,L)} + ε，L ∈ {5, 8, 12, 18}
（原始 n_init），c(f,L) = L/(2d_f + 1)（维度相对设计规模；筛选报告
推荐的分析轴）。参照档 L₀ = 5（harness 默认）。

- **对比估计量**：Δ_{f,L} = E_s[y_{f,s,L} − y_{f,s,L₀}]。
- **剂量斜率**：b_f = E_s[b_{f,s}]，b_{f,s} 为该种子在四档上对 c 的
  OLS 斜率（种子配对合法：同族同种子的各档共享 Sobol 前缀流）。
- **主检验** H0_slope：b_1 = … = b_F（公共剂量反应，无交互）。
- **次要检验** H0_pair：Δ_{f,12} 族间同质（与筛选实验直接可比，
  n = 60 与仅新种子 20–59 两个版本）。
- **机理方向假设**（沿用筛选实验的预宣告）：多峰族（Rastrigin、
  Ackley）b_f > 0；光滑族（Branin、Hartmann、SixHumpCamel）b_f < 0。
- **Rastrigin 深采样臂**（预宣告，按把握度选定样本量）：筛选实验的
  Rastrigin 结论若为真（d_z ≈ 0.5），n = 240 时 MDD₈₀ ≈ 3.5，效应
  应清晰可检；问题为"其剂量斜率是否为正"。

## 3. 设计

| 要素 | 设定 |
|---|---|
| 档位 | n_init ∈ {5, 8, 12, 18}；c 覆盖因族而异（d = 2：1.0–3.6×；d = 6：0.38–1.38×；d = 10：0.24–0.86× 启发式基准） |
| 预算 | 全档位 30 次评估（设计 + BO；逐轨迹校验 n_evals = 30） |
| 策略 | 各臂固定为 AlwaysSurrogate（隔离配置效应） |
| 配对 | 同族同种子跨档位共享 scrambled Sobol 前缀流 |
| 样本 | 主网格 60 种子/族（0–19 为筛选实验原样本，逐位复现；20–59 为新种子）；深采样臂仅 Rastrigin，240 种子 |
| 端点 | terminal best objective（backend 最大化约定） |
| 计算量 | 主网格 1200 条轨迹 106.8 s；深采样臂 960 条 32.8 s（24 workers） |

## 4. 方法

与筛选实验相同的推断框架：各族对比的种子级 percentile bootstrap CI
（5000）、配对 t、d_z、MDD₈₀ = 2.80·se、0.25·sd 精确零界；斜率以
种子级 OLS 斜率的均值 ± se 进入同质性 Wald χ²（连续 Cochran's Q，
df = F − 1）；机理符号的精确单侧二项检验；发现区（0–19，主网格按
种子三等分取 0–19 对齐筛选样本）/ 确认区（20–59）划分；LOFO 最优
档位预测（描述性）。预宣告判定：检出 ⇔ 主检验 p < 0.05；FUTILE ⇔
未检出且全族最优-对-参照对比达精确零界；否则 INCONCLUSIVE。

## 5. 结果

**各族水平均值与剂量斜率**（原始单位；per-sd 为斜率按参照档 sd
标准化的每单位 c 变化）：

| family | d | c 范围 | 水平均值 (L=5/8/12/18) | b_f | per-sd | p_slope | 最优档 |
|---|---|---|---|---:|---:|---:|---|
| Branin | 2 | 1.0–3.6 | −0.414 / −0.421 / −0.439 / −0.511 | −0.038 | −1.56 | 0.0023 | 5 |
| Hartmann | 6 | 0.38–1.38 | 2.825 / 2.762 / 2.549 / 2.376 | −0.470 | −0.84 | <10⁻⁴ | 5 |
| Ackley | 10 | 0.24–0.86 | −20.042 / −20.023 / −20.020 / −19.883 | +0.250 | +0.45 | 0.029 | 18 |
| SixHumpCamel | 2 | 1.0–3.6 | 0.901 / 0.901 / 0.868 / 0.772 | −0.052 | −0.30 | 0.0007 | 5 |
| Rastrigin | 10 | 0.24–0.86 | −116.73 / −114.29 / −116.15 / −112.38 | +5.67 | +0.40 | 0.120 | 18 |

光滑族的均值随档位单调下降；Ackley 在 L = 18 处抬升；Rastrigin
非单调且方差主导。

**主检验（参照标准化斜率同质性，尺度稳定；SE 取自联合种子
bootstrap——每个重抽样重复内 sd_ref 重新估计，其不确定性进入 SE）**：
χ²₄ = 20.06，**p = 5×10⁻⁴**，I² = 0.80，合并标准化斜率 −0.140。
原始单位斜率的次要版本（非尺度稳定、sd_ref 视为固定，仅作参考）：
χ²₄ = 30.87，I² = 0.87。**判定：CONDITIONALITY_DETECTED。**

**次要检验（Δ₁₂ 同质性，与筛选可比）**：n = 60 时 χ²₄ = 9.07，
p = 0.059；仅新种子 20–59 时 p = 0.114——两档单对比保持边缘，
凸显剂量形式化的检验力优势。

**个体确认（半区规则）**：Hartmann L = 18（Δ = −0.448 [−0.630,
−0.266]，d_z = −0.62）与 Branin L = 18（−0.097 [−0.162, −0.043]，
d_z = −0.40）通过发现/确认半区；SixHumpCamel 与 Ackley 的确认半区
CI 触零（边缘）；Rastrigin 全部未通过。

**机理符号检验**：5/5 一致（精确单侧 p = 0.031）。

**Rastrigin 深采样臂（n = 240）**：L = 18 对参照 +2.204 [−0.469,
4.824]，d_z = 0.106，p = 0.103；发现区（0–79）+3.97 对确认区
（80–239）+1.32（确认 CI [−1.88, 4.54] 含零）；斜率 b = +3.37，
双侧 p = 0.098（单侧 0.049）。**不复制筛选结论，且至多小效应。**

**描述量**：LOFO 最优档位预测 3/5（多数投票无特征输入；F = 5、
3:2 分裂下无分辨率，与筛选实验一致）。

## 6. 推断与解读

1. **主问题解决：配置条件性确立。** 族 × 剂量交互在 α = 0.05 下
   检出（联合 bootstrap SE 下 p = 5×10⁻⁴，I² = 80%）。初始设计规模
   的最优取值因问题族而异
   在本基准问题集上成立。
2. **异质性来源明确且机理一致。** 负斜率全部位于光滑族且逐族
   显著（危害方向、单调剂量反应）；正斜率位于多峰高维族，其中
   Ackley 显著（per-sd +0.45）、Rastrigin 边际。交互证据的结构与
   预宣告机理假设逐族吻合（符号 5/5，p = 0.031）。
3. **更正一：筛选实验的 Rastrigin 结论撤回。** 其 Δ₁₂ = +8.36
   （p = 0.032，半区规则"确认"）由种子区段 0–19 驱动；新增 40 种子
   均值 −3.30，n = 240 深采样臂效应至多 d_z ≈ 0.11。教训：族内
   种子方差极大时（Rastrigin 配对差 sd ≈ 19 原始单位），区块内
   半区确认规则不足以抵御区块间漂移——跨独立种子区块的复制才是
   有效确认。
4. **更正二（方法学）：单对比低检验力，剂量形式化解决。** 同一组
   60 种子上，Δ₁₂ 同质性 p = 0.059（边缘），四档斜率同质性
   p < 10⁻⁴。筛选实验的 INCONCLUSIVE 因此定性为**设计检验力不足**
   而非"无效应"——预宣告升级路径有效。
5. **oracle 与可学性。** 已知族标签的 oracle 档位选择在本基准问题集内有
   实质价值（光滑族选 5、多峰高维选 18；最优档位跨族不同）。但
   LOFO 无特征多数投票为 3/5，签名可学性仍未测——确立"应当按
   签名选配置"与证明"可从签名学到"之间，隔着特征化与 held-out
   预测两步（见 §8）。
6. **对元层方案的许可级别。** 按 guide §5.5.4 的分级：条件性已
   检出 ⇒ 元层方向获得筛选通过，**下一步投入的正当对象是签名特征
   与 held-out 预测**（小规模、便宜），而非直接铺设配置级监督管线。

## 7. 局限

- 档位网格为原始 n_init 等距；各族 c 覆盖范围不同（d = 10 族全部
  档位低于启发式基准，无法检验超配行为）。
- 策略固定为 AlwaysSurrogate；策略 × 配置交互未测。
- 基准问题集共 5 族，维度与族绑定（混杂）：Branin/SixHumpCamel 与 Ackley/
  Rastrigin 在 d 上不可分。
- Ackley 的确认半区 CI 触零（[−0.046, 0.249]），其个体显著性宜
  视为待复制；主检验不依赖任何单族。
- 深采样臂的样本量按筛选效应量预估；实际效应更小，n = 240 对
  per-sd ≈ 0.2 的效应检验力仍有限（边际结果按边际报告）。

## 8. 对研究方案的启示

1. 元层下一实验（预宣告方向）：以 (多峰性代理特征, d, c) 预测 held-out
   族的最优档位——最小设计为跨族 LOFO 逻辑回归 + 维度/多峰特征，
   评估集用未参与拟合的族与种子区块。
2. 基准问题集内的即时实用结论：光滑族不应对初始设计超配（本基准问题集内最优
   c ≈ 1×(2d+1) 或更低），多峰高维族受益于更高的设计占比——该
   结论是**候选基线**：须先通过 held-out 比较（赢家选择使用了同一
   份数据；Rastrigin 效应未获跨区块复制），方可进入基线组。
3. Rastrigin 型高方差族的任何族级结论，确认标准应提高为跨独立
   种子区块复制（≥ 2 个互斥区块 CI 同向排零）。
